# App icon

- `app_icon_source.svg`: the icon as drawn in Inkpad (the artboard holds
  the icon; drafts sit off the page).
- `app_icon_square.png`: 1024 px, full bleed and opaque — iOS, iPadOS and
  Android round its corners themselves.
- `app_icon_macos.png`: 1024 px, the rounded square with macOS's standard
  margin, on transparent.

Every platform's icon sizes (iOS, macOS, Android, web, Windows) were made
from these two PNGs.
